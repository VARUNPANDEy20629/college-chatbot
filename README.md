# 🎓 AI College Chatbot

An AI-powered college chatbot frontend built with **React.js** and **Vite**.  
The chatbot is designed to help students quickly access college-related information through a simple and interactive interface.

---

## 🚀 Features

- 🤖 AI-powered college chatbot interface
- 💬 Interactive chat experience
- 🎓 Designed for student and college-related queries
- ⚡ Fast and responsive React application
- 📱 Responsive user interface
- 🧩 Component-based architecture
- 🔥 Built using Vite for fast development
- 🖥️ Simple and user-friendly design

---

## 🛠️ Technologies Used

### Frontend
